Unreal Engine Shortcuts & Tips

Quick reference for Unreal Engine keyboard shortcuts by mode. Search or filter by mode.

Viewport Navigation
Master the viewport movement with RMB+WASD for flight, Alt+LMB for orbiting, and Scroll to zoom. Use G to toggle game view for real-time testing without leaving the editor.
Blueprint Productivity
Use keyboard shortcuts to place nodes faster: B+LMB for Branch, S+LMB for Sequence, C for Comments. Ctrl+Shift+F opens powerful Find-in-Blueprints for searching across all your scripts.
Material Editor Tricks
Use number pad hotkeys to quickly add nodes: 1+LMB for Scalar, 2+LMB for Vector, 3+LMB for Texture, 4+LMB for Color. L+LMB adds Lerp nodes and M+LMB adds Multiply.
