Key Papers

An Image Synthesizer (Perlin Noise)
Perlin — SIGGRAPH 1985
程序化生成的基石论文。提出 Perlin Noise 算法，通过梯度插值生成连续、自然的随机纹理。至今仍是地形生成、云层渲染、纹理合成的核心噪声函数，Perlin 凭此获得了奥斯卡技术成就奖。
Improving Noise (Simplex Noise)
Perlin — SIGGRAPH 2002
Perlin 对自己 1985 年算法的改进。引入 Simplex Noise，将计算复杂度从 O(2^n) 降低到 O(n²)，减少了方向性伪影。在高维噪声生成中效率更高，广泛用于现代游戏的地形和特效。
The Algorithmic Beauty of Plants
Prusinkiewicz, Lindenmayer — Springer 1990
L-System 的权威著作。系统阐述了如何用形式文法（Lindenmayer 系统）模拟植物的生长和分枝结构。从简单的重写规则出发，生成极其逼真的树木、花卉和藻类形态，是程序化植被生成的理论基础。
Example-Based Model Synthesis
Merrell — I3D 2007
Wave Function Collapse (WFC) 算法的学术先驱。提出从小型示例模型自动生成大型 3D 结构的方法，将 2D 纹理合成的思想推广到 3D。Maxim Gumin 后来将此思路简化为开源的 WFC 算法，在游戏关卡生成中广泛应用。
Real-Time Procedural Generation of 'Pseudo-Infinite' Cities
Greuter, Parker, Stewart, Leach — GRAPHITE 2003
实时程序化城市生成的早期重要论文。基于种子和规则系统在运行时生成无限延伸的城市环境，按需创建和销毁建筑物。为后来 No Man's Sky 等游戏的程序化世界生成提供了概念验证。
Large-Scale Terrain Authoring through Interactive Erosion Simulation
Cordonnier, Galin, Gain, Benes, Guerin, Peytavie, Cani — SIGGRAPH 2023
将交互式水力侵蚀模拟应用于大规模地形创作。结合 GPU 加速的物理模拟与艺术家的笔刷工具，实现实时可控的地形侵蚀效果，在程序化地形与手工创作之间取得了平衡。
