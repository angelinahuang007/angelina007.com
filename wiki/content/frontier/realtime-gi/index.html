Key Papers

Spatiotemporal Reservoir Resampling for Real-Time Ray Tracing with Dynamic Direct Lighting (ReSTIR)
Bitterli, Wyman, Pharr, Shirley, Lefohn, Jarosz — SIGGRAPH 2020
提出基于蓄水池采样的时空复用技术，在每像素仅追踪少量光线的情况下实现高质量直接光照。通过时间和空间上的样本共享，达到同等质量下 6-60 倍的加速，成为现代实时光追渲染的核心采样技术。
Dynamic Diffuse Global Illumination with Ray-Traced Irradiance Fields (DDGI)
Majercik, Guertin, Nowrouzezahrai, McGuire — JCGT 2019
提出基于探针（probe）的动态漫反射全局光照方案。在场景中放置 3D 网格探针，通过硬件光追更新探针的辐照度和可见性数据，实现实时动态 GI。被广泛应用于游戏引擎中。
Interactive Indirect Illumination Using Voxel Cone Tracing
Crassin, Neyret, Sainz, Green, Eisemann — Pacific Graphics / CGF 2011
提出体素锥追踪 (VCT) 方法，将场景体素化到 mipmap 3D 纹理中，然后追踪圆锥来近似积分。实现了交互式帧率下的漫反射和镜面反射间接光照，开创了基于体素的实时 GI 方向。
ReSTIR GI: Path Resampling for Real-Time Path Tracing
Ouyang, Bitterli, Jarosz, Yue — SIGGRAPH 2021
将 ReSTIR 的蓄水池重采样扩展到多次弹射的全局光照。不仅处理直接光照，还能高效复用间接光照路径，为实时全路径追踪迈出了关键一步。
Lumen: Real-time Global Illumination in Unreal Engine 5
Hillaire (Epic Games) — SIGGRAPH 2022 Advances in Real-Time Rendering
Epic Games 在 UE5 中的 Lumen 全局光照系统技术介绍。结合了屏幕空间追踪、软件光追和硬件光追等多种技术，在不同硬件条件下动态选择最优方案，实现了完全动态的实时 GI。
Light Propagation Volumes in CryEngine 3
Kaplanyan, Dachsbacher — SIGGRAPH 2010 Advances in Real-Time Rendering
提出光传播体积 (LPV) 方法，将光以球谐函数形式注入 3D 网格，然后迭代传播到相邻体素。首个在游戏中广泛应用的实时漫反射 GI 方案，被 CryEngine 3 和早期 UE4 采用。
