PBR Parameters

Metallic: 0 = dielectric (plastic, wood, etc.), 1 = conductor (gold, iron, etc.)

Roughness: 0 = mirror-like, 1 = diffuse. Controls specular highlight size.

Base Color: Albedo in dielectric mode, specular color in metal mode.

Fresnel Effect

Surfaces become more reflective at grazing angles. Described by Schlick's approximation:

F = F₀ + (1 - F₀)(1 - cos θ)⁵

F₀ varies: metals (~1.0), dielectrics (~0.04)
