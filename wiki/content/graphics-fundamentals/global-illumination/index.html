Global Illumination

Global Illumination (GI) simulates how light bounces around a scene, creating realistic shadows, color bleeding, and ambient lighting. Unlike direct lighting alone (which only shows light from the source), GI captures indirect light that reflects off surfaces, making scenes feel more naturally lit and three-dimensional.

Direct Lighting vs Global Illumination
Direct Lighting Only
Hard shadows, no light bouncing between surfaces, dark corners without detail.
With Global Illumination
Soft shadows, light color bleeding, illuminated corners, natural ambient lighting.

Color Bleeding (Light Bounces)

What it is: When light hits a colored surface (like a red wall), it bounces that color onto nearby surfaces. A white object next to a red wall will receive a pinkish glow from the reflected light.

Why it matters: Creates realistic color interaction between objects and makes scenes feel cohesive and natural.

Ambient Occlusion

What it is: Corners, crevices, and enclosed areas get darker because they receive less indirect light from all directions.

Why it matters: Adds depth and definition to scenes without complex light calculations.

Caustics

What it is: Light focused through glass or water creates bright, patterned shadows. Watch how light bends through a glass sphere.

Why it matters: Creates striking visual effects under water or through transparent objects.

Subsurface Scattering

What it is: Light penetrates semi-transparent materials (like skin, wax, or marble) and scatters inside, then exits as a glow.

Why it matters: Essential for realistic skin, plants, and translucent materials.

How It Works

Traces light rays through a scene using Monte Carlo integration. For each pixel, multiple random paths are traced. Each path bounces off surfaces, accumulating color until it hits a light or escapes the scene. More samples = less noise.

Convergence

As samples increase, random noise decreases and the image converges toward the mathematically correct solution. Noise roughly follows the square root of samples: 2x samples = sqrt(2) ≈ 1.4x less noise.

Strengths & Weaknesses

✓ Photo-realistic quality ✓ Handles any material/geometry ✓ Mathematically unbiased ✗ Slow for interactive use ✗ High noise at low samples

Real-World Use

Film rendering (Pixar, ILM), architectural visualization, high-end game cinematics.

How It Works

Divides surfaces into patches and calculates energy transfer between them. View-independent: computed once, then rendered from any angle instantly. Patch color accumulates light from all bounces.

Key Advantage

Pre-computed results are view-independent, so you can rotate the camera without recalculation. No noise—deterministic, smooth results immediately.

Strengths & Weaknesses

✓ View-independent ✓ No noise, smooth results ✓ Fast interactive rendering ✗ Complex math (form factors) ✗ Poor with dynamic objects

Real-World Use

Architectural pre-visualization, static game environments, pre-rendered cutscenes.

How It Works

Places invisible spheres throughout a scene that sample incoming light from all directions. Objects interpolate between nearby probes to estimate indirect lighting. Fast enough for real-time games.

Probe Placement

Grid-based (simple, uniform), or adaptive (more in complex areas). Denser grids capture more detail but cost more memory and computation.

Strengths & Weaknesses

✓ Real-time performance ✓ Supports dynamic objects ✓ Good for games ✗ Interpolation artifacts ✗ Memory for many probes

Real-World Use

Game engines (Unity, Unreal), VR, interactive experiences where speed matters.

How It Works

Uses existing depth buffer from the rendered scene to approximate occlusion. No pre-computation needed—works on already-rendered pixels. Fast but can only see screen-space geometry.

Screen-Space Limitation

Only geometry visible on screen contributes. Off-screen objects and complex bounces are missed. Best combined with other GI techniques for better results.

Strengths & Weaknesses

✓ Very fast (GPU-friendly) ✓ No pre-computation ✓ Works with dynamic geometry ✗ Artifacts at screen edges ✗ No off-screen occlusion

Real-World Use

Real-time ray tracing (RTX), modern game engines (mainly for ambient occlusion), VR.
